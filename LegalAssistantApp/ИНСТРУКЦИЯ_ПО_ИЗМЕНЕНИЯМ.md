## 🔧 Настройка проекта

### 1. Проверка зависимостей
Убедитесь, что в `LegalAssistantApp.csproj` есть все необходимые пакеты:
```xml
<PackageReference Include="Microsoft.EntityFrameworkCore" Version="8.0.0" />
<PackageReference Include="Microsoft.EntityFrameworkCore.Sqlite" Version="8.0.0" />
<PackageReference Include="CommunityToolkit.Mvvm" Version="8.2.1" />
```

### 2. База данных
База данных `legal_assistant.db` будет автоматически создана при первом запуске в папке с исполняемым файлом.

**Важно:** При каждом запуске база **пересоздаётся** и заполняется тестовыми данными. Это сделано для удобства разработки. В продакшене уберите строки:
```csharp
await context.Database.EnsureDeletedAsync();
```

### 3. Папка для документов
Документы сохраняются в: `%AppData%\LegalAssistant\Documents\`

## 📊 Структура базы данных

База содержит следующие таблицы с тестовыми данными (по 10 записей в каждой):
- `Users` - пользователи
- `Roles` - роли (Admin, Manager, Lawyer, Viewer)
- `Counterparties` - контрагенты
- `Documents` - документы
- `DocumentEvents` - события
- `DocumentTemplates` - шаблоны документов
- `AuditHistories` - история аудита
- `AuditLogs` - логи аудита

## ⚠️ Важные замечания

1. **База данных пересоздаётся при каждом запуске** - это сделано для удобства разработки. В продакшене уберите `EnsureDeletedAsync()`.

2. **Файлы документов копируются** в папку `%AppData%\LegalAssistant\Documents\` - убедитесь, что у приложения есть права на запись.

3. **Открытие файлов** использует системное приложение по умолчанию - убедитесь, что на компьютере установлены программы для просмотра соответствующих форматов.

4. **Версия приложения** отображается как "v1.0" в правом верхнем углу - можно изменить в `MainWindow.axaml`.

## 🆘 Решение проблем

### Ошибка "Database is locked"
- Закройте все подключения к базе данных
- Удалите файл `legal_assistant.db` вручную
- Перезапустите приложение

### Файлы не открываются
- Проверьте, что файл существует по пути `FilePath`
- Убедитесь, что на компьютере установлены программы для просмотра соответствующих форматов

### Ошибка при входе
- Проверьте, что база данных создана
- Убедитесь, что используете правильные логин/пароль из таблицы выше
